# Maintainers

Seedbank was created by James McCarthy and is canonically maintained at `james2m/seedbank`.

## Upstream

- **James McCarthy** (`james2m`) — creator and upstream maintainer

## Maintained fork

- **Stan Carver II** (`scarver2`) — maintainer of the `scarver2/seedbank` fork

This fork exists to keep Seedbank healthy on current Ruby and Rails releases while preserving the project's original purpose, public behavior, authorship, history, and MIT license. Changes developed here should remain suitable for focused upstream pull requests whenever practical.

The fork is intentionally not a competing reimplementation. Rails owns database seeding; Seedbank organizes Rails seeds.

For project history and the full contributor list, see `README.md` and the Git history.
